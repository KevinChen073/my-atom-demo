# MYATOM 界面设计原型 V4 · 待用户确认

这是一份**独立于正式工作台**的桌面可点击设计原型。它采用已讨论的 V3 品牌色、字体、图标和六页结构，同时落实最近一次体验评审提出的交互修改。当前状态为**设计候选，尚未得到用户确认**；不应据此修改正式产品的需求、架构或前端。

## 打开方式

在仓库根目录运行：

```powershell
py -3 -m http.server 8765 --bind 127.0.0.1 --directory design
```

然后打开 `http://127.0.0.1:8765/prototype-v4/`。纯静态 HTML、CSS 和 JavaScript，无安装步骤，不访问 `8000/8001` 或任何真实 API。`mock-backend.js` 用浏览器 `localStorage` 模拟项目、阶段和支出记录；点击顶部“恢复示例”可重置演示数据。**模拟保存不代表正式产品的数据持久化。**

## 本版请确认的设计点

1. **返回用户的首屏**先显示项目列表与搜索，右侧保留较紧凑的新建入口；首次使用时应以创建为首要动作。
2. **简单需求少问一次。** 已在原话中说清楚的信息进入“已明确”；只把尚有影响的选择交给用户。输入“今天的年月日”时，原型只追问时区。
3. **生成前右侧仍有用途。** 它显示已知信息、当前待办及明确的预览空状态；版本存在后才显示可操作的示例应用。
4. **对话记录先给结论。** 历史活动默认折叠；当前决定卡或结果卡占据主要视区，技术细节不铺满工作台。
5. **状态讲清证据。** 测试区把“示意通过”和“未执行”分开，发布区始终无假公网链接。

## 评审路径

| 路径 | 可体验的交互 |
| --- | --- |
| 所有项目 | 搜索三条示例项目、切换首次使用视图、填入示例需求、新建项目、帮助、恢复示例 |
| 项目切换器 | 搜索、选择目标项目；目标默认进入工作台，标题/对话/右侧一起更新 |
| 等待需求确认 | 查看已明确条件，回答一个关键问题，进入模拟计划 |
| 等待计划确认 | 阅读三步计划、填写修改意见、确认计划 |
| 模拟构建 | 明确标注无后台任务；手动切到模拟完成状态 |
| 已存版本工作台 | 预览/代码切换；“每周支出记录”的预览可添加记录并刷新读回 |
| 概览、文档、测试、发布 | 左侧对话保持，同项目只换右侧；文档四分类；测试说明展开；发布阻塞项 |

原型使用 hash 路由，便于直接打开、后退和前进。预览中的支出表单是单独的**模拟应用样板**，不声称根据输入需求生成了代码。新建项目即使走到“模拟构建完成”，代码区仍为示意内容。浏览器数据清除后，所有模拟新增内容会消失。

## 范围与确认门槛

- 目标视口：桌面 1280×720、1366×768、1440×900；不设计 MYATOM 手机界面。生成应用自身的移动适配由其需求决定。
- 继承 [交互说明](../INTERACTIONS.md) 的六页与项目切换规则，视觉基线来自 [V3](../v3/README.md)。原型中的“浏览器本地模拟保存”是设计演示手段，不更改 PRD 对正式产品真实持久化、构建和预览的要求。
- 请确认首屏排序、确认卡、生成前右侧区域、活动记录密度及六页视觉层级。获得确认后，才能把这一版作为正式界面实现依据；若有修改意见，先修订此原型并再次提交确认。
