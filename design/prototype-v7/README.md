# MYATOM 设计原型 V7 · 历史版本，仅供视觉参考

[打开 V7 原型](http://127.0.0.1:8765/prototype-v7/#/) · [查看 V6](http://127.0.0.1:8765/prototype-v6/#/)

这是用户于 2026-10-31 曾确认的独立桌面视觉原型。用户随后明确修订了对话与阶段显隐原则，当前要求以 [统一设计入口](../design.md) 和 [交互说明](../INTERACTIONS.md) 为准。本目录的可点击原型、代码与截图**尚未按该修订更新**，只用于回看 V7 视觉和排版，不能据此判定当前交互已实现。项目、对话阶段、预览、测试与发布状态均为浏览器内模拟；没有连接真实 Agent、后端、构建或发布服务。

## 与当前交互要求的已知差异

- 本原型仍有“过程记录”折叠列表；当前普通用户对话不应出现该开发者过程入口、模型调用数、Token 或常驻运行详情。
- 本原型虽然模拟了部分历史对话，但澄清、用户回答、计划确认、真实进展和结果尚未按服务端事实形成可恢复的完整时间线。当前要求是结构化决策卡嵌入 Agent 消息，提交后转为可回看的用户决定与只读摘要。
- 本原型在无版本时仍常驻右栏并展示空预览说明。当前要求是无可用版本默认隐藏右栏；计划形成后允许用户手动打开文档，首个可用版本完成后再提供预览/代码。
- 本原型的模拟构建与错误不能代表真实执行。当前失败消息需给出原因、下一步和可复制的 Trace ID，详细诊断留在受控后台。

## 本次样式决定

1. 字号使用 [V7 排版 token](tokens.json)。原有 9–13px 的界面文字提升到 14–17px，正文以 18px 为基准；标题层级为 21 / 24 / 26 / 34 / 50px。CSS 中以同名变量落实这些尺寸。1280×720 下导航仍完整，当前需求确认的品牌头像、选项、主按钮和输入同时可见。
2. 删除新建页装饰菱形、输入框下方的“先说清目标，细节可以稍后补充”、对话输入下方的“此处为界面草稿，提交不会调用模型”等冗余说明，并精简重复的模拟提示。模拟属性保留在原型标识、操作反馈及评审说明中。
3. 新建页标题依次呈现“今天想做什么？”“快速产出产品模型？”“一个绝妙的主意！”，每句打字完成后停顿，再逐字删除。动态标题不改变页面结构；系统选择减少动态效果时，静态显示第一句并隐藏光标。屏幕阅读器始终获得稳定的“今天想做什么？”标题。
4. 左上角的 `brand-mark.svg` 是 MYATOM 唯一的品牌图标。所有历史与当前 Agent 回复都使用同一图标；右侧空状态沿用该图标，去掉另一个菱形符号。

此历史原型沿用 V6 的三栏演示：左侧历史项目，中间对话，右侧项目内容。右侧视图切换不重建中间对话，草稿与阅读位置保留；新建页的三个样例卡只填入输入框，创建项目仍需用户点击主按钮。当前设计已把右侧改为按阶段显现，详见上述差异。
