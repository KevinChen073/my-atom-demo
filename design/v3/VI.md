# MYATOM 轻量 VI

## 核心概念

产品气质为“清晰的制作台”：用户的想法进入一个可操作的框架，经过澄清、计划、生成和验证，成为可查看的版本。品牌标记使用**两侧开口框与中央节点**；框是工作环境，节点代表当前正在处理的事。只在全局导航、项目中心和必要空状态出现，不在生成应用的预览内重复。

标记源文件：[brand-mark.svg](icons/brand-mark.svg)。字标：[brand-lockup.svg](icons/brand-lockup.svg)。最小标记尺寸 20px，推荐 28px；周围至少留一个中央节点直径的空白。深色底用白色框线与陶土节点，浅色底用墨绿框线与陶土节点。不得旋转成原子轨道，也不加发光外圈。

## 视觉规则

| 元素 | 规则 |
| --- | --- |
| 色彩比例 | 约 75% 暖白/纸白、20% 墨绿与冷灰、5% 陶土橙。橙色保留给当前主动作、待用户决定和品牌节点；成功/可用状态用深绿。比例是视觉指导，不是像素配额。 |
| 字体 | 正文使用系统中文无衬线；项目中心大标题可用系统宋体，形成“邀请开始”与工具界面的区别；工作台所有操作信息保持无衬线。版本、路径和日志用等宽。 |
| 线条 | 平台结构线 1px、低对比；选中导航有 3px 竖线；“输入→结果”细线与节点只用在阶段和版本关系上，不作为背景花纹。 |
| 项目标识 | 项目列表显示 2 字以内简称或用户指定图标，使用中性底色。生成应用的 favicon/品牌由该项目自己定义，不替 MYATOM 品牌。 |
| 形状 | 操作控件 8px 圆角、面板 12px；避免每块信息都成为等权卡片。预览容器边界比普通内容清楚，使用户知道其内是另一个应用。 |
| 文案 | 短句、可验证、直接指向下一步；真实阶段与版本名优先于抽象鼓励语。 |

## 应用到六页

- **项目中心**：品牌表达最明显，宋体展示标题配清晰的创建输入；项目列表以阅读效率为主，不做卡片墙。
- **工作台**：导航和对话后退，预览占最大面积；用户消息、待确认卡和版本结果有不同层级。预览内应用使用独立配色，避免误认 MYATOM 的 VI 是生成模板的一部分。
- **项目概览**：以当前阶段和下一步为主，用连续细线连接阶段，减少横向指标卡。
- **项目文档**：编辑式排版，标题、章节编号和目录分层；正文行长受控。
- **测试**：先读结论，再逐项看证据；通过、失败、未执行分别用字和图形。
- **发布**：明确“未发布/可发布/发布中/已发布”的差别；未具备能力时不出现假按钮或 URL。

## 产品边界

MYATOM 平台外壳持续使用上述 VI。预览中的生成应用拥有自己的标题、Logo、颜色和组件；平台只提供工具栏和容器边界。只有实际 `preview_ref` 可用时才展示可交互预览；本设计图中的应用仅用于版式说明。
