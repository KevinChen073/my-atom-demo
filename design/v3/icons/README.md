# 图标系统

工作台、概览、文档、测试、发布五个导航图标采用 20×20 画板、1.75px 线宽、圆角转折与统一视觉重量。默认跟随文字色；选中项使用品牌绿。图标始终与文字并列，不以孤立图形承担导航语义。状态图标须同时显示“通过 / 未执行 / 失败”等文字。

| 发布 | [publish.svg](publish.svg) |

项目列表的 2 字简称是项目身份标记，不使用这些导航图标，也不以无语义编号代替。搜索、添加、关闭、箭头等普通操作优先沿用同一风格的成熟基础图标，在前端实现时统一尺寸与对齐。
