# 视觉 Token 与组件规则

本目录的 [tokens.json](tokens.json) 是机器可读值；本文件说明使用方式。风格沿用已确认的“编辑台”：暖白背景、墨绿色信息主色、陶土橙只用于需要用户确认或重要提交的动作。项目中心与项目内五页共用同一套组件和密度。

## 颜色

| 语义 | Token | 值 | 用法 |
| --- | --- | --- | --- |
| 画布 | `canvas` | `#F6F5F1` | 页面外层 |
| 内容面 | `surface` | `#FFFEFB` | 对话、预览、文档 |
| 次级面 | `surfaceSoft` | `#F0F1EC` | 消息、选中导航和摘要 |
| 文字 | `text` | `#172522` | 标题、正文 |
| 次要文字 | `textMuted` | `#53635C` | 说明、时间、辅助状态 |
| 分隔 | `border` | `#D5DCD4` | 三大区域和少量表单边界 |
| 主信息/已完成 | `primary` | `#285E52` | 链接、选中页、完成状态 |
| 决策动作 | `decision` | `#A64B2B` | 确认计划、创建项目、可执行发布 |
| 警告 | `warning` | `#8A4C1E` | 待确认、未完成条件 |
| 错误 | `danger` | `#A43D34` | 失败与字段错误 |
| 焦点 | `focus` | `#2A6D61` | 键盘焦点描边 |

状态必须同时有短文字；颜色点只能辅助识别。文字、按钮、输入与状态组件在实施时逐项测量 WCAG AA 对比度（普通文字至少 4.5:1，大文字至少 3:1）；不能只凭色卡推断通过。

## 字体与层级

**采用方案 A**：中文和英文都用系统无衬线 `PingFang SC / Microsoft YaHei / Noto Sans CJK SC / system-ui`；路径、版本号和日志用 `Cascadia Code / ui-monospace`。无需下载字体。

备选 B：首页的展示标题可用 `Songti SC`，工作台仍保持无衬线。备选 C：全站系统无衬线，仅使用更强的字重层级。两种备选都不改变信息架构，当前页面图采用方案 A。

| 层级 | 尺寸 / 行高 | 使用位置 |
| --- | --- | --- |
| 展示标题 | 48px / 1.25 | 项目中心一句价值说明 |
| 页面标题 | 30px / 1.25 | 项目概览、文档、测试、发布 |
| 分区标题 | 22px / 1.25 | 列表与主内容章节 |
| 卡片标题 | 18px / 1.35 | 决策卡、结果摘要 |
| 正文 | 16px / 1.6 | 对话、说明、文档 |
| 紧凑正文 | 15px / 1.45 | 项目列表与表单 |
| 标签 | 14px / 1.45 | 导航、状态、按钮 |
| 元信息 | 13px / 1.45 | 时间、版本、路径 |

不使用 10–11px 表达关键问题、测试结论、导航或操作。正文阅读行长控制在约 28–40 个汉字。长文档在右侧提供最大约 760px 的阅读列。

## 空间、形状与布局

- 间距阶梯：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`。表单字段上下 16–24px；文档段落 24–32px；按钮与说明 8–12px。
- 顶部项目栏约 68px；左侧项目导航约 204px。预览可用时对话 400–440px，右侧剩余且尽量不少于 620px。MVP1 决策态没有预览时，对话区可更宽。
- 普通控件圆角 8px、卡片 12px、面板 14px。普通分区用浅边线和留白，不用投影堆叠卡片；只有弹层/抽屉使用轻阴影。
- 桌面目标视口：1280×720、1366×768、1440×900。低于 1280px 没有本版承诺的手机布局。生成应用的移动适配另行决定。

## 组件与状态

| 组件 | 默认/交互 | 空、加载、错误与键盘要求 |
| --- | --- | --- |
| 项目选择器 | 当前项目名 + 箭头；展开最近 5 项和搜索 | 无项目给“新建项目”；加载显示真实占位；错误保留当前标题；`Esc` 关闭并还焦点 |
| 项目列表行 | 名称、阶段、下一步、版本和更新时间；整行可进入 | 空列表给创建入口；搜索无结果给清空搜索；活动状态不靠颜色单独表达 |
| 左侧项目导航 | 当前项有底色和窄强调线 | 每项可键盘访问；当前项用 `aria-current=page`；徽标仅来自真实状态 |
| 对话输入 | 固定在中间栏底部；随项目隔离草稿 | 发送中禁重复提交；失败保留输入；切项目/刷新恢复后先核对服务端版本 |
| 决策卡 | 当前卡完整展开，旧卡压缩为摘要 | 必填未答显示字段原因；冲突保留草稿；确认按钮只在权威卡上出现 |
| 预览/代码 | 同一版本的两种视图 | 无有效预览时显示未就绪；失败显示原因与重载；切旧版标历史 |
| 测试行 | 执行名、状态、耗时、证据入口 | 未执行不能标通过；日志不可用时入口禁用并说明；展开后焦点仍在详情范围 |
| 发布条件 | 条件、阻塞原因、真实链接 | 无能力时无假发布按钮；请求中禁重复；成功后才能出现“打开应用” |
| 弹层/抽屉 | 项目切换、日志详情、发布确认 | 打开聚焦标题/首控件；`Esc` 关闭；焦点回触发项；不清空底层对话草稿 |

悬停约 120ms，面板过渡约 180ms，状态提示约 220ms；尊重 `prefers-reduced-motion`，减少动态效果时取消过渡与循环动效。焦点用 3px 可见描边，偏移 2px。

## 不采用的视觉做法

不使用深色大侧栏、等宽项目卡片墙、四类状态同屏平铺、虚构进度百分比、假预览截图、渐变发光 AI 背景或手机插图。项目中心突出“新建”和“继续”，项目内突出“对话”和“当前项目的真实成果”。
