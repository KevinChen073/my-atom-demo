# MYATOM 界面设计原型 V5 · 待用户确认

这是独立的桌面可点击设计候选。它沿用 [V3 设计 token](../v3/tokens.json) 与 [图标体系](../v3/icons/)，只使用静态 HTML、CSS、JavaScript 和浏览器 `localStorage` 模拟项目、阶段、预览数据；不会访问真实 API、模型、构建或发布服务。**本版尚未得到用户对原型的确认，不能作为正式前端实现依据。**

## 打开

在仓库根目录运行 `py -3 -m http.server 8765 --bind 127.0.0.1 --directory design`，然后打开 [V5 原型](http://127.0.0.1:8765/prototype-v5/)。V4 保留在相邻目录，便于比较。

## 本次结构调整

| 区域 | 角色 | 交互 |
| --- | --- | --- |
| 左侧 220px | 历史项目、搜索、所有项目、新建 | 点击项目进入该项目工作台，整套项目数据同步切换；不在这里堆项目状态页 |
| 中间，默认占余宽约 56% | 对话、当前决策、构建结果、固定输入 | 项目内切页时保持挂载，草稿和阅读位置不丢；有待确认卡时只在这里操作 |
| 右侧，默认约 44% | 预览、文件或项目状态内容 | 顶栏“工作台/概览/文档/测试/发布”只替换这里；可收起，也可放大到约 56% |

这里的比例以左侧扣除后的工作区域计算。两条分隔线可拖动，布局保存在当前浏览器；分隔线获得焦点后可用方向键每次调 16px、按住 Shift 调 48px、Home/End 到边界，双击分隔线或点“恢复默认布局”重置。预览放大只用于需要检查页面细节的时候；收起右侧时对话获得整个工作区域。状态入口处于项目顶栏，左侧始终是找回项目的空间。

## 页面和状态

主页面仍是六个：项目中心，以及项目内的工作台、概览、文档、测试、发布。项目内使用同一个对话区；切换历史项目时进入目标项目的工作台。工作台右侧有预览/代码页签，未生成版本时展示已知信息与明确的空状态，不画假预览。

这版请重点检查：

1. 左侧历史项目是否足够方便找回，是否需要增加分组或最近访问排序。
2. 中间对话的宽度、密度与输入位置是否符合你对“主要区”的预期。
3. 顶栏状态入口与右侧内容的关系是否一眼能懂。
4. 右侧默认、收起、放大三种宽度是否适合预览和读文档。

## 可体验路径

打开“每周支出记录”：中间看结果，右侧试用模拟应用或切到代码。输入一段迭代草稿，点击顶栏“项目文档”或“测试”，草稿保持。点击左侧“番茄钟待办”查看待确认需求，再回到“每周支出记录”，原草稿恢复。右上“收起右侧”可专注对话，点击任一状态入口会重新打开右侧。右侧标题旁“放大右侧”可临时检查内容。在 780px 以下的桌面高度，待确认时暂时隐藏普通迭代输入，让当前选择与确认按钮出现在首屏；确认后输入区恢复。

原型数据仅用于评审；每周支出记录表单写入当前浏览器本地存储，刷新后可读回，但不代表正式产品持久化。测试页的“示意通过”不是实际测试证据，发布页没有公网链接。
