# ADR-003：MYATOM 建造工作台只做桌面端

- 状态：Accepted（用户于 2026-10-31 明确提出）
- 关联：[PRD](../PRD.md)、[MVP1 界面](../MVP1-UI.md)、[设计方向讨论稿](../DESIGN-STANDARD.md)

## 决定

取消 **MYATOM 主站与建造工作台**的手机专用布局、触屏流程和移动视口验收。目标视口为 1280×720、1366×768、1440×900 的桌面浏览器。已有窄屏 CSS 可以保留，但不作为交付承诺，也不再投入新的移动适配设计工作。

该范围调整不决定**生成出来的应用**是否适配手机。生成应用的设备要求由用户需求、固定模板能力和后续验收计划分别确定。

## 理由与影响

笔试重点是需求澄清、计划确认、真实代码生成、交互预览与恢复。桌面空间可同时承载对话和预览，减少为了工作台手机布局而引入的页签、抽屉和草稿切换状态。设计验收改为桌面视口、键盘、错误/空状态与完整主流程。首次视觉方向图中的手机插图仅属探索，不代表交付范围。
