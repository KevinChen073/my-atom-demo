# ADR-032：同源预览放行与版本工作区

- 状态：Accepted（2026-11-02，用户明确要求）
- 关联：[PRD](../PRD.md)、[架构](../ARCHITECTURE.md)、[ADR-026](ADR-026-shared-origin-project-storage.md)、[版本验收](../../tests/cases/VERSIONS-PREVIEW.md)

## 决定

工作台允许加载与自身相同 origin 的已保存版本预览，不因 origin 相同而拦截。已有完整构建产物的历史模板版本也允许预览，不再以模板版本号拒绝。预览始终读取对应不可变快照的 `dist` 文件；缺少构建产物时仍明确报错。服务端继续验证邀请码会话、项目归属、一次性预览票据、短期会话和资源路径，这些是访问控制，不是浏览器脚本隔离。

右侧第五个页签由“发布”改为“版本”，路由为 `/projects/{id}/versions`；旧 `/publish` 路由仅兼容历史书签并显示版本页。版本页显示当前指针、最多 5 份快照的时间与构建结果，可临时预览旧版，并由用户明确执行“设为当前版本”。该动作只切换 `active_version_id`，不创建新快照，不回滚浏览器业务数据。公开发布不属于该页签，也不展示尚不存在的公开链接。

## 边界与验收

历史版本可能没有项目 ID 键前缀，且与当前浏览器业务数据格式不兼容；界面须提示回滚只恢复代码快照。共享 origin 的预览脚本可访问同源浏览器存储与接口，此决定不宣称安全隔离。公开入口仍按 [ADR-031](ADR-031-public-invite-access.md) 限定持码者生成与预览。

验收需核对同源预览正常载入、历史模板可载入、票据不可重放、跨项目版本不能借票据读取、版本页直达/刷新、临时查看不改变当前指针、切换后刷新仍指向目标版本。线上浏览器实测须另记，不以本地单测替代。
