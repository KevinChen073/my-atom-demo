# Atoms 单进程部署验收

依据 [ADR-018](../../docs/decisions/ADR-018-atom-single-process-static-branch.md)。本地自动测试只覆盖代码路径，不代表 Atoms 平台已通过。现场记录 URL、时间、脱敏日志、进程数、文件摘要和操作结果。

| ID | 通过判定 | 当前结果 |
| --- | --- | --- |
| AT-01 单进程 | 仅启动 `python -m backend.atom_serve`，API、工作台、`/ops/` 同端口可用；生成时无子进程或 Node。 | 本地假模型自动测试通过；Atoms 未执行。 |
| AT-02 Token | 无 Token 拒绝项目与异常查询；错误 Token 拒绝；正确 Token 登录后可访问，过期与退出后拒绝；公网 HTTPS 生效。 | 本地自动测试覆盖拒绝、登录和退出；公网未执行。 |
| AT-03 静态生成 | 确认计划后生成四文件，检查日志明确写明无 Node/浏览器检查，保存版含 `dist/index.html`、`style.css`、`app.js`；恶意外部资源被拒绝。 | 本地假模型自动测试通过；真实模型未执行。 |
| AT-04 持久化 | 创建项目、运行与版本，重启/替换进程后读回项目、事件游标、checkpoint、产物和当前版本。 | 未执行；需平台持久目录。 |
| AT-05 预览隔离 | 每项目独立 HTTPS origin；同项目跨版本刷新读回 `localStorage`，另一项目脚本无法读取；票据过期和 CSP 生效。 | 本地同进程路由自动测试通过；平台通配域/TLS/浏览器未执行。无通配域时预览 503。 |
| AT-06 模型与完整旅程 | 平台真实模型完成澄清、计划、生成、静态检查、版本保存；浏览器点击、刷新、重进与回滚手动验证。 | 未执行。 |

AT-01 至 AT-06 全部通过后，才能把 Atoms 分支视为有真实在线闭环。静态检查通过不得替代浏览器交互验收。
