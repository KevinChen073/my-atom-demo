# 版本页与同源预览验收（ADR-032）

状态：用例定义；本地自动检查与线上浏览器结果分别记录。

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| VP-01 同源预览 | 打开有 `dist/index.html` 的版本，在工作台点击预览；检查 iframe URL 和载入结果。 | 工作台与预览可为同一 origin，页面不以“未隔离”为由拦截；应用真实界面出现。 |
| VP-02 历史模板 | 打开旧模板标识、但仍有完整构建文件的快照。 | 能取得票据并载入快照；若业务数据格式不兼容，只说明数据边界，不把快照隐藏。 |
| VP-03 访问控制 | 无邀请码、重放票据、替换项目/版本 ID 或越界资源路径。 | 服务端继续拒绝未授权或过期请求；这些检查不代表同源脚本隔离。 |
| VP-04 版本页 | 直接访问 `/projects/{id}/versions` 并刷新；从旧 `/publish` 书签进入。 | 最后页签为“版本”，展示当前快照及最多 5 个版本；旧书签显示版本页，不显示虚假的公开发布信息。 |
| VP-05 临时查看与回滚 | 在版本页预览旧版，刷新项目确认当前指针未变；再明确点击“设为当前版本”，刷新项目与预览。 | 临时查看不修改 `active_version_id`；切换后服务端指针持久化，预览对应目标快照，不创建第 6 个版本。 |
| VP-06 业务数据 | 在有业务数据的浏览器回滚代码版本。 | 工作台说明 `localStorage` 不随代码回滚；人工核对旧代码能否读取现有数据。 |

本地自动测试覆盖 VP-02/03 的服务端路径、VP-04 的直达路由和前端构建。VP-01/04/05/06 的真实浏览器体验需在目标部署版本上线后实测，记录环境、版本 ID、URL、时间与结果。
