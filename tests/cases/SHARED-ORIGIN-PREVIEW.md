# 共享 origin 预览验收（ADR-026）

状态：**本地定向测试已部分执行，Azure 在线验收未执行**。路由、票据与模板适配器已有自动化证据；浏览器端跨版本和云端验收仍按下表执行。依据：[ADR-026](../../docs/decisions/ADR-026-shared-origin-project-storage.md)、[PRD](../../docs/PRD.md)、[架构](../../docs/ARCHITECTURE.md)。

| ID | 操作 | 预期 / 判定 |
| --- | --- | --- |
| SO-01 同源路径 | 本地与 Azure 分别打开工作台、两个项目的预览；记录 `location.origin`、实际 URL、iframe 与静态 JS/CSS 请求。 | 工作台和预览 origin 相同；预览经 `/preview/...` 路径加载，资源路径、刷新与重新载入均可用；Azure 默认 HTTPS FQDN 无 wildcard 配置。 |
| SO-02 前缀与版本 | 项目 A 的 v1 写入待办，刷新、重进、生成 v2、切回 v1。检查 `localStorage` 键。 | 仅写 `myatom.app.<A 的规范化 UUID>.*`；同项目跨版本读回，不加入版本 ID；代码回滚不清理业务数据。旧 origin 数据不会被静默宣称已迁移。 |
| SO-03 正常跨项目操作 | 项目 A/B 各写不同任务，在两个预览间切换、刷新、删除 A 的一条任务；检查键与 UI。 | 正常模板路径只访问本项目前缀，B 的键与 UI 不受 A 操作影响；生成代码不得调用 `localStorage.clear()`、枚举删除其他前缀或直接使用无前缀键。 |
| SO-04 存储失败 | 禁用 Web Storage 或注入 `setItem` 抛错，再保存业务数据。 | 页面明确报错，不宣称保存成功；不转写平台数据库或服务端业务 CRUD。 |
| SO-05 票据与服务端归属 | 让预览票据/会话过期、替换版本 ID、替换资源路径、用 B 的会话请求 A 的版本。 | 服务端拒绝过期、越权和非法路径；工作台可重新签发票据。此项只证明服务端文件访问控制，不证明浏览器同源脚本隔离。 |
| SO-06 同源风险取证 | 用受控测试产物在 A 预览中枚举 B 前缀和 `myatom.model-config.v1`；尝试以当前访客身份请求平台 API。只用虚构业务数据和测试 Key。 | 明确记录同源代码能触及的其他项目键和接口；本地与 Azure 点击保存后的 Key 均可被同源脚本读取，刷新后仍存在；这是已知暴露风险。**不得**将前缀、CSP、iframe sandbox 或票据标为跨项目/密钥安全隔离。测试 Key 立即清除。 |
| SO-07 环境门禁 | 目标代码迁移后，在无 `PREVIEW_BASE_DOMAIN` 的本地/`azure_demo` 启动；检查 Azure 默认 FQDN，入口限制及 `APP_ENV=container_smoke`。 | 共享路径模式可启动，旧 Host 路由不再是必需；健康模式仍只开放健康检查。现有镜像在代码改完前不适用。 |
| SO-08 受信演示出口 | 使用获授权测试身份完成生成、预览、刷新、版本回滚和容器重启读回。 | 业务链路有真实证据；Azure SQL 连通、入口限制和模型 Key 风险处理均另有通过记录。未完成时仍标为阻塞，不能把镜像健康当作产品可用。 |

执行记录须包含环境、Git 提交、镜像摘要、项目/版本 ID、测试 Key 是否已清除、实际 URL、脱敏截图与 Pass/Fail/Blocked。SO-06 是**预期暴露的边界证明**，不是安全通过项。若产品目标恢复为跨项目保密或公开任意生成代码，应先修订 ADR-026，再重新设计 `TC-SEC-01`。
