## 执行准备与判定规则

- 固定同一浏览器、100% 缩放；分别设置**实际 CSS 视口**为 1280×720、1366×768、1440×900，记录 `innerWidth/innerHeight/devicePixelRatio`。每页各取一张全页截图（6×3=18），弹层、错误、加载和减少动效状态另拍。截图命名 `v3-{width}-{page}-{state}.png`，记录构建版本、浏览器、源项目和时间。1280 以下仅观察，不作为本轮桌面验收门槛。
- 用两个同一访客可访问项目：A 有真实已保存版本、可用预览及业务记录；B 处于澄清或计划待确认，拥有与 A 不同的需求/消息。再准备 A 的一次失败运行和上一个成功版本，测试页有真实可读取日志。使用隔离测试数据/固定假模型建立状态，不发付费模型请求；若页面没有服务端数据，标未验证，不能以示意内容代替。发布能力未接通时必须处于未发布/阻塞态。
- 先核对 API 返回的项目、run、版本、事件与预览状态，记脱敏 ID；浏览器中的标题、阶段、消息、测试、发布提示与之比对。页面导航、卡片确认和预览 CRUD 使用真实 UI 点击/输入；只读脚本可测尺寸、computed style、可访问名称与控制台。直接 URL、后退/前进、刷新均纳入。
- **阻断项**：跨项目串数据、未确认就生成、假预览/假测试通过/假公网链接、同项目切页丢未提交决策、主要页面不可访问或真实操作失效。视觉差异按影响范围记 P1/P2；设计图与产品能力冲突时，以真实服务端事实和 PRD 为准并记差异。

## 路由、切换与草稿连续性

| ID | 步骤 | 通过标准 |
| --- | --- | --- |
| DV3-N01 同项目五页 | 在 A 工作台填写未提交消息/决策答案，记中间对话滚动位置、当前卡、右侧版本与预览/代码页签；依次点概览→文档→测试→发布→工作台。 | URL 和左导航高亮同步；仅右侧主内容变化，中间对话节点保持挂载、草稿/卡片选择/滚动不丢；返回工作台恢复版本与页签。快速连点导航只落最终目标，不出现重叠内容。 |
| DV3-N02 跨项目切换器 | 从 A 任一项目内页面点左上项目名，检索 B，再键盘 `Esc`、重开并用方向键/`Enter` 选 B；查最近 5 项、“所有项目”“新建项目”和无匹配。 | 打开即聚焦搜索；`Esc` 关并回触发器；选 B 后进入 `/projects/B` 工作台，标题、消息、右侧、版本与状态都属于 B；不短暂出现 A 内容挂 B 标题。新建入口回项目中心并聚焦输入，**不先建空项目**。 |
| DV3-N03 返回项目与卡片过期 | A/B 各填不同未提交草稿；在 B 待确认卡输入但不提交，切 A 再回 B；使 B 卡在服务端变旧后再返回。 | 草稿按项目与 `card_id/spec_version` 隔离。返回 B 恢复草稿并核对当前卡；旧卡不能直接确认，给出冲突与比较/更新路径。切换不重发 run。 |
| DV3-N04 浏览器历史与直达 | 从 A 文档切 B，再后退/前进；直接打开 A 的五页 URL、刷新；用无权或不存在的 ID 直达。 | 历史还原对应项目和页，服务端重新核验；刷新可恢复。不因历史导航创建 run；无权/不存在不泄漏消息，提供“返回所有项目”。 |
| DV3-N05 构建中切换 | A 构建时记录 run ID/事件 seq，切 B、返回 A 并刷新。 | A 在服务端继续原 run，进度/版本与事件回放一致；无第二次生成或假百分比。切换时先隐藏 A，B 只显示自己的骨架/数据。 |

## CSS token、可访问性与动效

| ID | 检查方法 | 判定 |
| --- | --- | --- |
| DV3-T01 语义色与比例 | 对全局导航、画布、表面、文字、边线、主动作、待确认、成功/警告/失败抽样 computed style，和 `design/v3/tokens.json` 比对；截图人工查看面积关系。 | 暖白/纸白主导、墨绿与冷灰次之、陶土橙只用于品牌节点/当前主动作/待决。约 75/20/5 为视觉指导，不做像素硬阈值；状态不可只靠颜色。预览内部配色不纳入平台 token 比对。 |
| DV3-T02 字阶/间距/形状 | 测导航/正文/大标题/日志的 font-family、font-size、line-height；量 topbar、sidebar、chat、preview，抽查圆角与 20px 图标。 | token 目标：topbar 68px、sidebar 208px、chat 约 424px、预览不小于 620px；控件 8px、卡片 12px、预览 14px；正文 16px、页标题 30px、日志等宽。浏览器缺字体时记录回退字体，不把系统替代判为功能失败。1280 宽仍不横向溢出。 |
| DV3-T03 图标与品牌 | 20px 实际尺寸查看五个项目导航 SVG，检查线宽/端点、文字标签、选中竖线；查看品牌标记在浅/深底。 | 五图标视觉重量一致，不能用旧 Unicode 占位符；图标与文字一起表达语义。品牌为开口框+节点，无旋转原子轨道/光圈；生成应用内部不重复平台标记。 |
| DV3-T04 键盘/对比 | `Tab` 走项目选择器→左导航→对话→右侧；按 `Enter/Space/Esc` 操作；抽样文本与背景对比，检查焦点。 | 普通文字对比至少 4.5:1；焦点环 3px、offset 2px 或同等明显；页面切换焦点到右侧标题，历史返回焦点回触发器；所有主要动作有可访问名称。状态更新有文字/图形及必要播报。 |
| DV3-M01 短促反馈 | 录制 hover/focus、切换器、同项目换页、跨项目切换、确认卡、预览就绪；记录触发、实际时长、终态/中断。 | 约 120ms hover、180ms 弹层、160ms 右侧切页、220ms 反馈；跨项目旧内容立即清除再约 160ms 骨架。真实服务端确认前不演成功，未知总量不画百分比；快速切换无残影或多组同时滑动。 |
| DV3-M02 减少动态效果 | 在浏览器/系统启用 `prefers-reduced-motion: reduce` 后重复项目切换、卡片确认、预览就绪与加载/失败态。 | 空间移动和淡入即时完成；按钮和焦点可用，加载/成功/失败仍有文本/图标。不得只靠动画传递状态，不出现无限装饰循环。 |

## 三栏宽度拖动与本地恢复（新增；执行结果见过程记录）

范围是桌面项目页的左导航、中间对话、右侧工作区；A 为有真实预览的项目，B 为待澄清项目。先清除**本应用专用的布局偏好**（不要清空整个浏览器存储），记录 `innerWidth`、三栏与两条分隔线的 `getBoundingClientRect().width/x`、相关 localStorage 键和值及截图。以 1440×900 完成主操作，再在 1366×768、1280×720 复核；只使用隔离项目，不触发付费模型调用。布局宽度是本浏览器的用户界面偏好，默认在 A/B 间沿用；它不能改动项目数据、当前 run、预览业务记录或路由。若产品明确改为每项目布局，需要先更新本节的跨项目预期。

| ID | 操作步骤 | 通过标准 |
| --- | --- | --- |
| DV3-R01 默认与可发现性 | 清除布局偏好并刷新 A 工作台；找到左/中、中/右两条拖动分隔线；用鼠标悬停、Tab 定位。 | 初始宽度接近 V3 默认比例；两条把手能被视觉/指针识别，不覆盖导航、对话输入、预览工具栏；键盘可聚焦，具有可访问名称和当前尺寸/范围信息。无布局偏好时不出现空白或跳动。 |
| DV3-R02 左/中拖动 | 在 1440 宽按住左/中分隔线向右约 80px，再向左约 40px，释放；记录两次前后宽度。 | 左导航宽度随指针同向变化，中间对话相应调整；右侧宽度按约束稳定或合理联动，三栏总宽不超出视口。拖动中不选中文字、不触发导航/卡片、无 iframe 截获导致拖动中断；释放后把手位置和宽度一致。 |
| DV3-R03 中/右拖动与真实预览 | 在 A 的真实预览已载入时，将中/右分隔线分别向左、右拖动约 80px；随后在预览里点击一项业务记录并切换代码/预览。 | 对话与右区随指针反向分配空间；预览不被复制、重启 run 或变成模拟内容，代码/预览和版本选择仍可用。拖动经过 iframe 边缘时指针捕获/拖动遮罩有效，释放后不残留遮罩。 |
| DV3-R04 边界与窄宽 | 两条分隔线分别连续拖到两端，覆盖 1440、1366、1280；先记录边界位置，随后把窗口缩到 1280，再恢复 1440。 | 宽度在明确的最小/最大值处钳制；1280 时优先保持预览至少 620px（或设计明确的受限态），对话/确认卡仍能阅读和操作；无水平滚动、重叠、分隔线跑出屏幕或无限抖动。窗口缩窄不会把已存的超大宽度硬套进小视口；恢复后布局可继续拖动。记录实际钳制值，不能只看 CSS 声明。 |
| DV3-R05 刷新与跨页 | 调整到非默认宽度，记三栏实测值；刷新 A 工作台，依次打开概览、文档、测试、发布，再回工作台；直接访问 A/docs 并刷新。 | 刷新和直达后读取同一应用布局偏好（允许像素级四舍五入），五页保持同一三栏分隔；同一单页会话中的未提交草稿、当前 run、右侧页签/版本不因拖动而被提交或重建；硬刷新仅验布局偏好与服务端状态，不把未提交草稿的跨刷新持久化混入本用例。localStorage 只保存布局所需的非敏感数据，不含需求正文、票据或密钥。 |
| DV3-R06 项目切换 | 在 A 调宽后用切换器进入 B，再回 A；记录两项目三栏尺寸、消息和右侧状态。 | 同浏览器界面宽度偏好沿用，B 的待确认内容仍属 B，A 的版本/预览仍属 A；切换时旧项目立即隐藏，不能因宽度恢复出现 A 内容挂 B 标题。回到项目中心后创建表单仍可正常使用。 |
| DV3-R07 键盘与重置 | Tab 到两条分隔线，分别用方向键增减宽度，检查焦点环与读屏名称；执行产品提供的“恢复默认布局”动作（可为可见按钮、快捷键或分隔线双击），随后刷新。 | 键盘操作每次有稳定且可感知的宽度变化，受同一边界约束；不会滚动整个页面或误激活邻近按钮。重置后立即回 V3 默认尺寸并更新/删除保存值；刷新后仍为默认。重置方式必须可由键盘完成，不能只依赖双击鼠标。 |
| DV3-R08 存储异常降级 | 仅在隔离测试夹具或隔离浏览器中预置本应用布局键为无效 JSON/越界数值（或模拟存储不可用）后刷新，再恢复原值。 | 应用回退到合法默认/钳制宽度；六页可访问且无未捕获异常，拖动仍可用（存储不可用时仅不承诺刷新恢复）；不会清除项目或业务数据。 |

逐条记录初始/结束三栏宽度、视口、把手的 ARIA 信息、localStorage 键和值的**结构/数值**、刷新后宽度、截图与浏览器错误；不要把其他本地存储内容抄入证据。拖动幅度只用于观察变化，允许实现采用自身边界与取整规则；偏差超过约 3 CSS px、无法恢复或影响真实预览时记缺陷。DV3-R08 如测试环境无法安全隔离存储，标 `Not run`，不得为此清空用户浏览器数据。2026-10-31 本轮 R01–R07 已通过，R08 部分通过；详见 `D:\AI\ATOM笔试\docs\DESIGN-V3-VERIFICATION.md`。新增功能验收**不回改此前 106/120 的 V3 评分**。
