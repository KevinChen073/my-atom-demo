# 公开首页与邀请码测试空间验收（ADR-031）

状态：本地定向测试中；Azure 入口仍受 IP 限制，公网验收未执行。

| 用例 | 操作 | 通过条件 |
| --- | --- | --- |
| TC-INV-01 公开首页 | 从未登录浏览器打开首页与项目列表 | 首页可打开，项目列表为空；创建项目、run、版本、预览、模型测试请求被 401 拒绝，即使提交自带 Key 也不能生成 |
| TC-INV-02 邀请码身份 | 用配置的邀请码在两台浏览器登录；分别新建/打开项目 | 同码共享项目和版本；网络不返回原码或服务端模型 Key；Cookie 为 Secure、HttpOnly、SameSite=Strict |
| TC-INV-03 错码与撤销 | 输入错码五次；伪造 Cookie；更换或移除容器 `MYATOM_INVITE_CODE` 并重启 | 错码限流；伪造和旧会话不能访问项目或使用平台 Key；新码不自动取得旧码项目 |
| TC-INV-04 项目访问 | 已认证与未认证浏览器交叉请求项目、run、版本与预览；认证浏览器退出 | 服务端拒绝未认证访问；退出后项目不可访问；同码两台设备共享项目 |
| TC-INV-05 模型模式与额度 | 持码者用平台额度或自带 Key 创建 run；达到每日调用/Token 上限 | 两种模式路由正确；平台 Key 不进入页面、文件、异常和日志；额度耗尽不能继续调用平台 Key |
| TC-INV-06 公开入口 | 部署后从不同网络访问 HTTPS 地址 | 首页可访问；匿名无法生成/预览；持码可完成生成、预览、版本读回；记录时间、修订和脱敏证据 |

现有同容器 Runner 与同源预览没有对持码恶意代码的隔离保证。邀请码只发给受信测试者；若范围扩大，须新设计并测试隔离方案。
